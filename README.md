# Alvik Match Control

ตารางสายการแข่งขัน จับเวลา และบันทึกผล สำหรับ Arduino Alvik Smart Logistics Challenge (9 ทีม)

เปิดใช้งานที่ https://raphael-nt.github.io/alvik-match-control/ หรือดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดได้เลย ไม่ต้องต่อเน็ต ใช้ได้ทั้งคอมพิวเตอร์ iPad และโทรศัพท์

## รูปแบบการแข่งขัน

| คู่ | รอบ | รูปแบบ | ผู้แข่ง |
|---|---|---|---|
| P1 | รอบคัดเลือก | Bo3 | สาย 8 กับ สาย 9 |
| Q1 ถึง Q4 | รอบ 8 ทีม | Bo3 | สาย 1-2, 3-4, 5-6, 7 กับผู้ชนะ P1 |
| S1, S2 | รอบรองชนะเลิศ | Bo3 | ผู้ชนะรอบ 8 ทีม |
| F | ชิงชนะเลิศ | Bo5 | ผู้ชนะ S1 กับ S2 |

## หน้า

- **แดชบอร์ด** (`#dashboard`) สำหรับเปิดบนจอใหญ่ แสดงคู่ที่กำลังแข่ง นาฬิกา คะแนนสด คู่ถัดไป ตารางแข่ง และอันดับ
- **จับเวลา** (`#timer`) สำหรับโต๊ะกรรมการ นาฬิกา บันทึกระหว่างแข่ง และตารางผลแต่ละเกม
- **สายการแข่งขัน** (`#bracket`) จัดสาย สุ่มจับสาย และดูผลทั้งสาย
- **กรรมการ** (`#ref`) สำหรับมือถือหรือ iPad กดนับแท่น บันทึกเวลา และจบเกม

เปิดหลายหน้าพร้อมกันในเครื่องเดียวได้ เช่น แดชบอร์ดบนโปรเจกเตอร์ และหน้าจับเวลาบนจอโน้ตบุ๊ก ทุกหน้าจะอัปเดตตามกันเอง การเชื่อมข้ามเครื่องจะเพิ่มทีหลัง

## ใช้งาน

**หน้าสายการแข่งขัน**
- พิมพ์ชื่อทีมในช่องสาย 1-9 แล้วกด "สุ่มจับสาย" สองครั้ง ชื่อจะเปิดทีละสาย
- กด "ปลดล็อคสาย" เพื่อลากสลับสาย หรือแตะปุ่ม ⠿ ของสองสายต่อกัน กด "ล็อคสาย" เมื่อจัดเสร็จ
- ย้ายสายไม่ได้หลังเริ่มบันทึกผลแล้ว
- กล่องอันดับด้านล่างอัปเดตเองเมื่อแต่ละคู่จบ

**หน้าจับเวลาและบันทึกผล**
- "เซ็ตอัพแล้วต่อเกม" นับเซ็ตอัพ 1:00 แล้วนับ 3-2-1 เข้าเกม 1:30 เอง
- เลือกแบบสนาม 1-3 ที่จับฉลากได้ของเกมนั้น
- ระหว่างแข่งกด `-` `+` นับแท่น และกด ยกแรก ครบ 3 ออกกรอบ เพื่อบันทึกเวลาที่ผ่านไปลงช่องเอง
- กด "จบเกม และตัดสินผล" หรือรอหมดเวลา ระบบตัดสินตามกติกาข้อ 6.1-6.4
- ถ้าผลเสมอ ให้กรรมการกดเลือกผู้ชนะในตาราง
- "คู่ถัดไป" ข้ามไปคู่ที่พร้อมแข่ง ปุ่ม Space เริ่มหรือหยุดนาฬิกา Ctrl+Z ย้อนกลับ

**เก็บผลลง Excel**
- Chrome หรือ Edge บนคอมพิวเตอร์ กด "เชื่อมไฟล์ Excel" แล้วเลือก `Alvik_Bracket.xlsx` ผลจะบันทึกลงไฟล์ให้เอง
- เบราว์เซอร์อื่น ใช้ปุ่มนำเข้าและดาวน์โหลด .xlsx แทน
- ข้อมูลเก็บในเบราว์เซอร์ด้วย ปิดแล้วเปิดใหม่ข้อมูลยังอยู่

## ไฟล์

- `index.html` หน้าเว็บทั้งหมดในไฟล์เดียว รวมฟอนต์และ SheetJS
- `Alvik_Bracket.xlsx` ไฟล์ Excel เปล่าสำหรับเชื่อมเก็บผล
