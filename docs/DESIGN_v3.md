# Alvik Match Control v3 ดีไซน์ระบบกรรมการ และหน้าเว็บทั้งหมด

สถานะ ดีไซน์ ยังไม่ได้ทำโค้ด ฉบับแก้ครั้งที่ 2 (ปรับตามที่เจ้าของงานตอบ 13 พ.ย. 2569) เอกสารนี้ต่อยอดจาก `DESIGN.md` (v2 ที่ใช้งานอยู่) ส่วนไหนไม่ได้พูดถึง ให้ถือตาม v2

อ้างอิง กติกาการแข่งขันหุ่นยนต์ Arduino Alvik (ข้อ 1 ถึง 7) และ FAQ ฉบับ 10 พฤศจิกายน 2569 (ถาม 1 ถึง 36) ถ้าเอกสารนี้ขัดกับกติกา ให้ยึดกติกา

## หลักที่เจ้าของงานกำหนด

1. **แข่งทีละคู่** สนามแข่งเดียว (โต๊ะเดียว สองสนามวางคู่กัน ทีมแดงกับทีมน้ำเงินแข่งพร้อมกัน) ตัดระบบหลายสนามออกทั้งหมด
2. **นาฬิกากลางเรือนเดียว** ต่อเกม ไม่แยกฝั่ง
3. **แต่ละเกณฑ์กดครั้งเดียว** กรรมการกดสีของฝั่งที่ทำได้ก่อน ระบบจำว่าฝั่งไหนก่อน และ ณ เวลาเท่าไร
4. **กด Mission complete แล้วเวลาหยุดทันที** เกมจบ

## 2. กติกาที่ระบบต้องรู้

- Setup 1:00 ภารกิจ 1:30 นับจากสัญญาณเริ่ม (ข้อ 3)
- สุ่มแบบสนาม 1 ถึง 3 ก่อน Setup สองทีมใช้แบบเดียวกัน (2.3) ทีมวางแท่นเอง กรรมการตรวจก่อนเริ่ม (FAQ 4)
- หุ่นทุกส่วนต้องอยู่ในกรอบแดงตอนเริ่ม (FAQ 3) ออกก่อนสัญญาณ กรรมการหยุดและเริ่มใหม่ทั้งสองทีม (FAQ 12)
- เหตุการณ์ที่ใช้ตัดสิน
  - **ออกตัวสำเร็จ** ทุกส่วนพ้นกรอบแดง (5.3) นับครั้งแรก Retry ไม่ลบ (FAQ 28)
  - **ยกแท่นแรกสำเร็จ** ขา 4 ขาลอยพ้นพื้นพร้อมกัน (5.1, 5.2) นับครั้งแรก (FAQ 28)
  - **ครบภารกิจ** แท่นที่ 3 จอดสำเร็จ กรรมการหยุดเวลาทันที (FAQ 33)
  - **จำนวนแท่นที่จอดสำเร็จ** ณ หมดเวลา (5.6) ช่องละ 1 แท่น (FAQ 19) หลุดแล้วไม่นับ (FAQ 21) ถือค้างไม่นับ (FAQ 22)
- เกณฑ์ตัดสินตามลำดับ (ข้อ 6) ครบภารกิจก่อน (6.1), แท่นมากกว่า (6.2), ยกแท่นแรกก่อน (6.3), ไม่มีใครยกได้ ออกกรอบก่อน (6.4), เท่ากันทุกอย่างแข่งใหม่แบบสนามเดิม (FAQ 34), ไม่มีใครออกกรอบ กรรมการตัดสิน (FAQ 35)
- Retry ไม่มีโทษ ไม่จำกัด เวลาเดินต่อ แท่นที่จอดแล้วยังนับ (ข้อ 7, FAQ 13, 27, 29)
- กรรมการรับรองผล ทีมถามได้ก่อนรับรอง คำตัดสินถือเป็นที่สุด (FAQ 36)

**ผลของการ "กดครั้งเดียวต่อเกณฑ์"** เกณฑ์ 6.3 และ 6.4 ถามแค่ว่าใครก่อน ดังนั้นพอกรรมการกดฝั่งที่ทำได้ก่อน เกณฑ์นั้นก็ตัดสินได้แล้ว ไม่ต้องรู้เวลาของฝั่งที่ช้ากว่า เวลาที่เก็บไว้ใช้แสดงผลและตรวจย้อนหลัง

**กรณีพร้อมกัน** ถ้าสองฝั่งทำได้พร้อมกันจนกรรมการแยกไม่ออก มีปุ่ม **Same time** ในเกณฑ์นั้น ใช้เป็นทางไปสู่การแข่งใหม่ตาม FAQ 34

## 3. สถานะของเกม

```
Idle       เรียกคู่ขึ้นสนามแล้ว ยังไม่เริ่มเกมนี้ เลือกแบบสนาม
Setup      นับ 1:00 ทีมวางแท่น วางหุ่น
Ready      Setup จบหรือกดข้าม รอ Pre-start checklist ครบ
Countdown  กด Start แล้ว นับ 3 2 1
Live       นาฬิกากลางเดิน 1:30 กดเหตุการณ์ได้
Review     หมด 1:30 หรือกด Mission complete ตรวจผลก่อนรับรอง
Done       รับรองแล้ว ไปเกมถัดไปหรือจบคู่
```

| จาก | ไป | เกิดเมื่อ |
|---|---|---|
| Idle | Setup | กด Start setup (เลือกแบบสนามแล้ว) |
| Setup | Ready | หมด 1:00 หรือกด Skip setup |
| Ready | Countdown | กด Start (Pre-start checklist ครบ) |
| Countdown | Live | ครบ 3 วินาที เวลา GO (`go_at`) กำหนดที่เซิร์ฟเวอร์ ทุกจอนับพร้อมกัน |
| Countdown หรือ Live | Ready | กดค้าง **False start** ลบเหตุการณ์ทั้งหมดของรอบนี้ แบบสนามเดิม (FAQ 12) |
| Live | Review | กด **Mission complete** (นาฬิกาหยุดที่เวลานั้น) หรือนาฬิกาถึง 1:30 |
| Review | Done | กด Confirm result |
| Review | Idle (เกมใหม่ แบบเดิม) | ผลเสมอทุกอย่าง กด Replay (FAQ 34) |
| Done | Idle (เกมถัดไป) | คู่ยังไม่จบ |
| Done | ว่าง รอคู่ถัดไป | คู่จบ |

ไม่มี Pause ระหว่างเกม (กติกาไม่มีการหยุดเวลา) เหตุสุดวิสัยใช้ False start หรือให้แอดมินแก้

## 4. หน้ากรรมการ (Referee) `/ref/`

มือถือแนวตั้งหรือ iPad ปุ่มใหญ่ จอไม่ดับ (Wake Lock) สั่นเมื่อบันทึกสำเร็จ ใช้ **เครื่องเดียว** ต่อการแข่ง (เครื่องที่สองเปิดได้แบบดูอย่างเดียว ถ้าเครื่องแรกเสีย แอดมินโอนสิทธิ์ให้)

### 4.1 Sign in

ช่อง PIN ปุ่ม **Sign in** จำ PIN ในเครื่อง

### 4.2 Waiting

ยังไม่มีคู่บนสนาม ขึ้น "Waiting for next match" พร้อมคู่ถัดไปและเวลานัด ไม่มีปุ่มอื่น (กันกรอกผิดคู่) เมื่อแอดมินเรียกคู่ จอเปลี่ยนเองทันที

### 4.3 Match

```
┌─────────────────────────────┐
│ A2   Group A   Game 2 of 3  │
│ Series  1 - 0               │
├─────────────────────────────┤
│ RED   ทีมสอง                 │
│ BLUE  สาม                    │
├─────────────────────────────┤
│ Field pattern               │
│ [ 1 ] [ 2 ] [ 3 ]  [Random] │
├─────────────────────────────┤
│ [     Start setup 1:00    ] │
│ Skip setup     Team absent  │
└─────────────────────────────┘
```

- เลือกแบบสนามเอง หรือ **Random** (2.3) Dashboard ขึ้นแบบสนามทันที ล็อกเมื่อเริ่ม Setup เกม Replay ล็อกแบบเดิมไว้แล้ว
- **Team absent** ส่งคำขอแพ้บายให้แอดมินอนุมัติ

### 4.4 Setup

- นาฬิกากลางนับ 1:00 ลง
- **Pre-start checklist** ต้องครบก่อนปุ่ม Start จะกดได้
  - [ ] Red robot fully inside red box (FAQ 3)
  - [ ] Blue robot fully inside red box
  - [ ] Stands placed as pattern N, both sides (FAQ 4)
- หมด 1:00 เปลี่ยนเป็น Ready เอง พร้อมเสียง

### 4.5 Start

- ปุ่ม **Start** เต็มจอ กดครั้งเดียว
- เลข **3 2 1** ใหญ่ เสียงติ๊ด 3 ครั้ง เสียงยาวตอน **GO** Dashboard นับพร้อมกัน
- ระหว่างนับถอยหลังและระหว่างเกม มีปุ่ม **False start** (กดค้าง 1 วินาที)

### 4.6 Live

นาฬิกากลางอยู่บนสุด ใต้ลงมาเป็น Checklist ตามลำดับเกณฑ์ แต่ละแถวมีปุ่มแดงกับน้ำเงิน **กดฝั่งที่ทำได้ก่อนเพียงครั้งเดียว** แถวนั้นจะเปลี่ยนเป็นบรรทัดสรุป "RED first 0:02.4" และปุ่มหายไป แถวที่ควรกดต่อจะเด่น แต่ทุกแถวกดได้เสมอเพราะเหตุการณ์จริงอาจข้ามลำดับ

```
┌─────────────────────────────┐
│          1:12.4             │
│   Pattern 2      Live       │
├─────────────────────────────┤
│ 1 Left red box first (5.3)  │
│   RED first   0:02.4    ✓   │
├─────────────────────────────┤
│ 2 First lift (5.1)          │
│   [  RED  ]     [  BLUE  ]  │
│        Same time            │
├─────────────────────────────┤
│ 3 Stands parked now (5.4)   │
│  RED  [-] 2 [+]  BLUE [-] 1 [+]│
├─────────────────────────────┤
│ 4 Mission complete (6.1)    │
│   [  RED  ]     [  BLUE  ]  │
├─────────────────────────────┤
│ Retry  R 1   B 0   [ Undo ] │
│ If time ends now: RED (6.2) │
└─────────────────────────────┘
```

**1 Left red box first** กดสีของหุ่นที่พ้นกรอบแดงทุกส่วนก่อน ระบบเก็บฝั่งและเวลา ณ วินาทีที่กด

**2 First lift** กดสีของฝั่งที่ยกแท่นได้ (ขา 4 ขาพ้นพื้น) ก่อน ป้ายช่วยจำ "4 legs off the floor"

**Same time** ใต้ข้อ 1 และ 2 ใช้เมื่อแยกไม่ออกจริง ๆ ว่าใครก่อน

**3 Stands parked now** ตัวนับต่อฝั่ง 0 ถึง 3 เพิ่มลดได้ตลอดเกม (แท่นหลุดจากช่อง FAQ 21 ให้ลด) ป้ายช่วยจำ "Pushed or dragged in does not count" ข้อนี้เป็นข้อเดียวที่บันทึกทั้งสองฝั่ง เพราะเกณฑ์ 6.2 ต้องใช้จำนวนของทั้งคู่

**4 Mission complete** กดสีของฝั่งที่จอดแท่นที่ 3 สำเร็จ **นาฬิกากลางหยุดทันที** เกมเข้าสู่ Review ฝั่งที่กดคือผู้ชนะตาม 6.1 ปุ่มนี้ต้องกดค้าง 0.5 วินาทีกันกดพลาด และระบบตั้งตัวนับของฝั่งนั้นเป็น 3 ให้เอง

**Retry** นับจำนวนครั้งต่อฝั่งไว้ดู ไม่มีผลต่อคะแนน (7.5)

**Undo** ย้อนการกดล่าสุด ทีละ 1 ครั้ง จนถึงเริ่มเกม (Undo Mission complete ได้ภายใน Review ดูข้อ 4.7)

**If time ends now** บอกว่าถ้าหมดเวลาตอนนี้ใครชนะ ด้วยข้อไหน

เวลาที่บันทึกมาจากนาฬิกาเครื่องกรรมการที่ปรับให้ตรงกับเซิร์ฟเวอร์แล้ว เน็ตช้าจึงไม่ทำให้เวลาเพี้ยน

### 4.7 Review

```
┌─────────────────────────────┐
│ Time up 1:30                │
│  (หรือ Stopped 1:05.2)       │
├─────────────────────────────┤
│ Left red box first  RED 0:02.4│
│ First lift          RED 0:18.0│
│ Stands at end   RED 2  BLUE 1 │
│ Mission complete    -        │
│ Retries         RED 1  BLUE 0 │
├─────────────────────────────┤
│ Result   RED wins           │
│ Rule 6.2 more stands parked │
├─────────────────────────────┤
│ [ ] No stand held by robot  │
│ [ ] Teams have seen result  │
│ [      Confirm result     ] │
└─────────────────────────────┘
```

- ทุกบรรทัดแตะแก้ได้ เพื่อให้ตรงสภาพจริง ณ ตอนจบ (FAQ 21, 22) การแก้ใน Review ติดป้ายในประวัติ
- จำนวนแท่น ณ ตอนจบ แก้ได้เฉพาะเมื่อหมดเวลา กรณีจบด้วย Mission complete ไม่ต้องใช้
- **Result** คำนวณจากข้อ 6 พร้อมเหตุผล 1 ประโยค
- เสมอทุกอย่าง ปุ่มเปลี่ยนเป็น **Replay with pattern N** (FAQ 34)
- ไม่มีใครออกกรอบแดง ปุ่มเปลี่ยนเป็น **Referee decides** เลือก Red หรือ Blue (FAQ 35)
- ติ๊ก 2 ข้อให้ครบก่อน **Confirm result** (FAQ 36)

### 4.8 Next

คู่ยังไม่จบ แสดงผลซีรีส์และปุ่ม **Next game** กลับไปหน้า Match คู่จบ ขึ้น **Match finished** แล้วกลับสู่ Waiting

### 4.9 สิ่งที่หน้ากรรมการทำไม่ได้

เรียกคู่ขึ้นสนาม แก้คู่ที่จบแล้ว แก้เกมที่รับรองแล้ว สลับฝั่งทีม ตัดสินแพ้บาย ทั้งหมดเป็นงานแอดมิน

## 5. Dashboard (เดิมจอ TV) `/dashboard/`

จอ 1920x1080 พื้นมืด ไม่มีปุ่มกด

### 5.1 โหมด Live (มีคู่บนสนาม)

```
┌──────────────────────────────────────────────────────────┐
│ [logo] Arduino Alvik Smart Logistics Challenge  ● Online │
│ Round 1  Group A  Match A2  Game 2 of 3   Pattern 2      │
├──────────────────────────────────────────────────────────┤
│   RED  ทีมสอง          1 - 0          BLUE  สาม           │
│                                                          │
│                       1:12.4                             │
│                        LIVE                              │
│                                                          │
│   Stands  ▣▣□  2                      ▣□□  1   Stands    │
│   Left red box first   RED 0:02.4                        │
│   First lift           waiting                           │
├──────────────────────────────────────────────────────────┤
│ Bracket (ตารางสายเส้นลากแบบย่อ)          │ Up next  A3  B3 │

```

- **นาฬิกากลาง** ใหญ่ที่สุดในจอ บอกช่วง Setup Ready Countdown Live Stopped Time up แดงใน 10 วินาทีสุดท้าย

- กด Mission complete นาฬิกาหยุด ขึ้น "RED mission complete 1:05.2"
- ผลจบเกม ขึ้นแถบ 8 วินาที "RED wins Game 2 Rule 6.2"
- หัวจอบอก **รอบ สาย คู่ เกม แบบสนาม**
- ล่างจอ **ตารางสาย** แบบย่อ และ **Up next** พร้อมเวลานัด

### 5.2 โหมดอื่น

| โหมด | ใช้เมื่อ | เนื้อหา |

| **Bracket** | ไม่มีคู่บนสนาม | ตารางสายเต็มจอ พร้อม Up next |
| **Standings** | ประกาศผลรอบ | ตารางคะแนนทุกสาย |
| **Schedule** | ช่วงพัก | ลำดับคู่ทั้งหมด เวลานัด สถานะ |
| **Draw** | จับสาย | เผยชื่อทีมทีละทีม |
| **Champion** | จบคู่ชิง | แชมป์ รองแชมป์ อันดับรวม |

Auto มีคู่บนสนามใช้ Live ไม่มีใช้ Bracket จบคู่ชิงใช้ Champion แอดมินบังคับโหมดได้

## 7. ข้อมูล

### 7.1 สนาม

`a2_field` เหลือแถวเดียว (no = 1) ตัด `field_count` ออกจาก `a2_event` และตัด `sched_field` ออกจาก `a2_match` ฟิลด์ใหม่

- `phase` เพิ่มค่า `ready` `countdown` `stopped`
- `go_at` เวลาเซิร์ฟเวอร์ตอน GO ทุกจอใช้คำนวณนาฬิกา
- `stop_ms` เวลาที่นาฬิกาหยุด (Mission complete)
- `checks` jsonb ผล Pre-start checklist

### 7.2 ตาราง `a2_mark` บันทึกเหตุการณ์

| คอลัมน์ | ชนิด | ความหมาย |
|---|---|---|
| `id` | uuid | สร้างที่เครื่องกรรมการ กันส่งซ้ำ |
| `game_id` | bigint | เกม |
| `kind` | text | `exit_first` `lift_first` `park` `unpark` `complete` `retry` `false_start` |
| `side` | text | `red` `blue` หรือ `both` (Same time) |
| `t_ms` | int | เวลาตั้งแต่ GO ตามนาฬิกาเครื่องกรรมการที่ปรับแล้ว |
| `voided` | bool | ถูก Undo หรือแอดมินลบ |
| `source` | text | `live` `review` `admin` |
| `device` `created_at` | | ใครกด และเวลาที่เซิร์ฟเวอร์ได้รับ |

ตรวจที่เซิร์ฟเวอร์ `exit_first` `lift_first` `complete` มีได้อย่างละ 1 แถวที่ไม่ถูก void ต่อเกม `t_ms` อยู่ระหว่าง 0 ถึง `game_ms`

### 7.3 ค่าสรุปในแถว `a2_game` (คำนวณใหม่ทุกครั้งที่มีเหตุการณ์)

| คอลัมน์ | มาจาก |
|---|---|
| `exit_side` `exit_ms` | แถว `exit_first` |
| `lift_side` `lift_ms` | แถว `lift_first` |
| `complete_side` `complete_ms` | แถว `complete` |
| `red_parked` `blue_parked` | ผลรวม park ลบ unpark ต่อฝั่ง (0 ถึง 3) ค่า ณ ตอนจบ |
| `red_retries` `blue_retries` | จำนวน retry |

### 7.4 ตัวตัดสิน `a2_decide` v3

```
1  มี complete_side                 ฝั่งนั้นชนะ               6.1
   (นาฬิกาหยุดทันที จึงมีได้ฝั่งเดียว ยกเว้นกรรมการกดแบบ both = เสมอ ไปข้อ 3)
2  red_parked ไม่เท่า blue_parked   มากกว่าชนะ               6.2
3  มี lift_side
     red หรือ blue                  ฝั่งนั้นชนะ               6.3
     both                           replay                  FAQ 34
4  ไม่มี lift_side
     exit_side red หรือ blue        ฝั่งนั้นชนะ               6.4
     exit_side both                 replay                  FAQ 34
     ไม่มี exit_side                judge                   FAQ 35
```

### 7.5 RPC กรรมการ

| RPC | ทำอะไร |
|---|---|
| `a2_ref_claim(pin, device)` | ขอเป็นเครื่องกรรมการ ถ้ามีเครื่องอื่นใช้อยู่ใน 30 วินาทีล่าสุด ได้สิทธิ์ดูอย่างเดียว |
| `a2_ref_pattern(..., game, n or 'random')` | เลือกหรือสุ่มแบบสนาม |
| `a2_ref_setup(..., 'start' or 'skip')` | Setup |
| `a2_ref_check(..., item, on)` | ติ๊ก Pre-start checklist |
| `a2_ref_go(...)` | เริ่มนับถอยหลัง `go_at = now() + 3s` |
| `a2_ref_false_start(...)` | void เหตุการณ์ทั้งหมด กลับ Ready |
| `a2_ref_mark(..., id, kind, side, t_ms)` | บันทึกเหตุการณ์ (`complete` หยุดนาฬิกาด้วย) |
| `a2_ref_undo(..., id)` | void เหตุการณ์ |
| `a2_ref_review_set(..., key, value)` | แก้ค่าใน Review |
| `a2_ref_confirm(..., game)` | รับรองผล คืน `red` `blue` `replay` `judge` |
| `a2_ref_judge(..., game, side)` | ตัดสินตาม FAQ 35 |
| `a2_ref_absent(..., side)` | ขอแพ้บาย |

RPC แอดมินใหม่ `a2_adm_call(pw, code)` เรียกคู่ขึ้นสนาม `a2_adm_clear(pw)` เอาคู่ลง `a2_adm_ref_transfer(pw)` ปลดเครื่องกรรมการเดิม `a2_adm_mark(pw, ...)` แก้เหตุการณ์

### 7.6 คิวออฟไลน์ของกรรมการ

ทุกการกดเก็บลงเครื่องก่อน แล้วส่ง ส่งไม่สำเร็จลองใหม่ทุก 2 วินาที จอขึ้น "Saved on this phone, sending (3)" ปุ่ม Confirm result รอจนคิวว่าง

## 8. Realtime และเวลา

- ทุกจอคำนวณนาฬิกาจาก `go_at` `stop_ms` และค่าเหลื่อมเวลากับเซิร์ฟเวอร์ (`a2_now`)
