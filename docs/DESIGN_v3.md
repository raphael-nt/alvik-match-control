# Alvik Match Control v3 ดีไซน์ระบบกรรมการ และหน้าเว็บทั้งหมด

สถานะ ดีไซน์ ยังไม่ได้ทำโค้ด เอกสารนี้ต่อยอดจาก `DESIGN.md` (v2 ที่ใช้งานอยู่) ส่วนไหนไม่ได้พูดถึง ให้ถือตาม v2

อ้างอิง กติกาการแข่งขันหุ่นยนต์ Arduino Alvik (ข้อ 1 ถึง 7) และ FAQ ฉบับ 10 พฤศจิกายน 2569 (ถาม 1 ถึง 36) ถ้าเอกสารนี้ขัดกับกติกา ให้ยึดกติกา

## 1. สิ่งที่เปลี่ยนจาก v2

| เรื่อง | v2 ตอนนี้ | v3 |
|---|---|---|
| ชื่อหน้าจอใหญ่ | จอ TV (`/tv/`) | **Dashboard** (`/dashboard/`) ส่วน `/tv/` เปลี่ยนเป็นหน้าพาไปที่ใหม่ |
| Dashboard | ตารางสาย ไม่มีนาฬิกา | มี **นาฬิกา** ของทุกสนาม **รอบที่กำลังแข่ง** และ **ตารางสายหรือตารางคะแนน** อยู่ในจอเดียว |
| หัวข้อในทุกหน้า | ภาษาไทย | หัวข้อ ชื่อแท็บ และชื่อปุ่มหลักเป็น **ภาษาอังกฤษ** เนื้อหาคำอธิบายยังเป็นไทย (ตารางคำศัพท์ในข้อ 9) |
| เริ่มเกม | กดเริ่มจับเวลาแล้วนับทันที | กด **Start** แล้วนับถอยหลัง **3 2 1** พร้อมเสียง จึงเริ่มนับ 1:30 |
| การกดคะแนน | ปุ่ม +1 แท่น กับปุ่มประทับเวลา | **Checklist ตามเกณฑ์การตัดสิน** ไล่ตามลำดับเหตุการณ์ในเกม ทุกครั้งที่กด ระบบจำเวลาจริงของฝั่งนั้นทันที |
| ข้อมูลเกม | เก็บเป็นตัวเลขสรุปในแถวเกม | เก็บเป็น **บันทึกเหตุการณ์** (event log) ทุกการกด แล้วคำนวณผลจากบันทึก ย้อนดูได้ทุกวินาที |
| จอดแท่น | นับจำนวน 0 ถึง 3 | กดเป็น **ช่องจอด 3 ช่อง (ซ้าย กลาง ขวา)** ต่อฝั่ง ตรงกับสนามจริง และกัน "ช่องเดียวนับ 2 แท่น" (FAQ 19) |
| ครบ 3 แท่น | ประทับเวลา | นาฬิกาของฝั่งนั้น **หยุดทันที** (FAQ 33) อีกฝั่งเดินต่อ ทั้งคู่ครบเกมจบเลย |
| เกณฑ์เสมอ | ยกแท่นเท่ากันแล้วไปเทียบออกกรอบ | แก้ให้ตรงกติกา ข้อ 6.4 ใช้เฉพาะเมื่อ **ไม่มีทีมไหนยกได้** ถ้ายกได้ทั้งคู่และเวลาเท่ากัน คือเสมอทุกอย่าง แข่งใหม่ (FAQ 34) |
| กรรมการต่อสนาม | เครื่องเดียวกดทั้งสองฝั่ง | เลือกได้ต่อสนาม **1 เครื่อง** หรือ **2 เครื่อง (แดง 1 น้ำเงิน 1)** แนะนำ 2 เครื่องเพราะเหตุการณ์ออกกรอบของสองฝั่งมักห่างกันไม่ถึงวินาที |
| เน็ตหลุด | กดไม่ได้ | ทุกการกดมีรหัสไม่ซ้ำและเวลาจากเครื่อง จึง **เก็บคิวไว้ในเครื่องแล้วส่งตามทีหลังได้** ผลไม่เพี้ยน |

## 2. กติกาที่ระบบต้องรู้ (สรุปเฉพาะที่กระทบระบบ)

- เวลา Setup 1:00 เวลาภารกิจ 1:30 นับจากสัญญาณเริ่ม (ข้อ 3)
- สุ่มแบบสนาม 1 ถึง 3 ก่อนเริ่ม Setup ทั้งสองทีมใช้แบบเดียวกัน (ข้อ 2.3) ทีมวางแท่นเองช่วง Setup กรรมการตรวจก่อนเริ่ม (FAQ 4)
- หุ่นทุกส่วนต้องอยู่ในกรอบแดงตอนเริ่ม (FAQ 3) ออกตัวก่อนสัญญาณ กรรมการหยุดและเริ่มใหม่ทั้งสองทีม (FAQ 12)
- เหตุการณ์ที่ต้องจับเวลา นับจากสัญญาณเริ่ม
  - **ออกตัวสำเร็จ** ทุกส่วนพ้นกรอบแดง (5.3) ใช้ครั้งแรกเท่านั้น Retry แล้วไม่หาย (FAQ 28)
  - **ยกแท่นแรกสำเร็จ** ขาทั้ง 4 ลอยพ้นพื้นพร้อมกัน (5.1, 5.2) ใช้ครั้งแรกเท่านั้น (FAQ 28) ยก 2 ขาไม่นับ (FAQ 18)
  - **ครบภารกิจ** เวลาที่แท่นที่ 3 จอดสำเร็จ กรรมการหยุดเวลาทันที (FAQ 33)
- สภาพแท่นที่จอดเปลี่ยนได้ตลอดเกม หลุดออกจากช่องไม่นับ (FAQ 21) ย้ายช่องได้ (FAQ 23) ช่องละ 1 แท่น (FAQ 19) ถือค้างเหนือช่องตอนหมดเวลาไม่นับ (FAQ 22) **ผลใช้สภาพ ณ 1:30 หรือ ณ ตอนครบภารกิจ** (5.6)
- Retry ไม่มีโทษ ไม่จำกัดครั้ง เวลาเดินต่อ แท่นที่จอดแล้วยังนับ (ข้อ 7, FAQ 13, 27, 29) ต้องแจ้งกรรมการทุกครั้ง (FAQ 30)
- เกณฑ์ตัดสินตามลำดับ (ข้อ 6)
  1. **6.1** ครบ 3 แท่นชนะทีมที่ไม่ครบ ครบทั้งคู่ เวลาครบน้อยกว่าชนะ
  2. **6.2** ไม่มีใครครบ จำนวนแท่น ณ หมดเวลามากกว่าชนะ
  3. **6.3** เท่ากัน (จำนวนเท่า หรือครบเวลาเท่า) ยกแท่นแรกก่อนชนะ ยกได้ทีมเดียว ทีมนั้นชนะ
  4. **6.4** ไม่มีใครยกได้เลย ออกกรอบแดงก่อนชนะ
  5. ยังเท่ากันทุกอย่าง แข่งใหม่ทันทีด้วยแบบสนามเดิม (FAQ 34)
  6. ไม่มีใครออกกรอบแดง กรรมการตัดสิน (FAQ 35)
- กรรมการประจำสนามรับรองผล ทีมถามได้ก่อนรับรอง คำตัดสินถือเป็นที่สุด (FAQ 36)

**ความละเอียดเวลา** เก็บเป็นมิลลิวินาที แต่ **เทียบผลที่ 0.1 วินาที** (ปัดลงแบบตัดทศนิยมที่ 2 ทิ้ง) เพราะการกดของคนคลาดได้ราว 0.1 ถึง 0.2 วินาที ค่า `tie_ms = 100` ตั้งได้ในหน้า Settings แสดงผลบนจอเป็น `0:05.3`

## 3. สถานะของเกม (state machine ต่อสนาม)

```
Idle      ยังไม่เริ่มเกมนี้ เลือกแบบสนาม
Setup     นับ 1:00 ทีมวางแท่น วางหุ่น
Ready     Setup จบหรือกรรมการกดข้าม รอ Pre-start checklist ครบ
Countdown กด Start แล้ว นับ 3 2 1 (3 วินาที)
Live      นับ 1:30 กดเหตุการณ์ได้
Review    หมดเวลา หรือครบทั้งสองฝั่ง ตรวจผลก่อนรับรอง
Done      รับรองผลแล้ว ไปเกมถัดไปหรือจบคู่
```

การเปลี่ยนสถานะ

| จาก | ไป | เกิดเมื่อ |
|---|---|---|
| Idle | Setup | กรรมการกด Start setup (ต้องเลือกแบบสนามแล้ว) |
| Setup | Ready | หมด 1:00 หรือกด Skip setup |
| Ready | Countdown | กด Start (เปิดได้เมื่อ Pre-start checklist ครบ) |
| Countdown | Live | ครบ 3 วินาที (เวลาเริ่ม `go_at` กำหนดที่เซิร์ฟเวอร์ ทุกจอนับพร้อมกัน) |
| Countdown หรือ Live | Ready | กด **False start** (กดค้าง) ลบเหตุการณ์ของรอบนี้ทั้งหมด แบบสนามเดิม (FAQ 12) |
| Live | Review | ถึง 1:30 หรือทั้งสองฝั่งครบ 3 แท่น |
| Review | Live | ไม่มี (หมดเวลาแล้วย้อนไม่ได้) ส่วนแก้ข้อมูลทำในหน้า Review |
| Review | Done | กด Confirm result |
| Review | Idle (เกมใหม่ แบบเดิม) | ผลเสมอทุกอย่าง กด Replay (FAQ 34) |
| Done | Idle (เกมถัดไป) | คู่ยังไม่จบ |

ไม่มีปุ่ม Pause ในเกม เพราะกติกาไม่มีการหยุดเวลา (Retry เวลาเดินต่อ) ถ้ามีเหตุสุดวิสัย ให้ใช้ False start หรือให้แอดมินแก้

## 4. หน้ากรรมการ (Referee) `/ref/`

ใช้บนมือถือแนวตั้งเป็นหลัก iPad ได้ ปุ่มใหญ่ กดด้วยนิ้วโป้งได้ จอไม่ดับระหว่างเกม (Wake Lock) สั่นเบา ๆ ทุกครั้งที่บันทึกสำเร็จ

### 4.1 Sign in

- ช่อง PIN ปุ่ม **Sign in**
- จำ PIN ในเครื่อง ครั้งหน้าไม่ต้องกรอก

### 4.2 Select field

- การ์ดสนามละใบ กดได้เฉพาะสนามที่แอดมินเปิดคิวแล้ว (เหมือน v2)
- ถ้าสนามตั้งเป็นโหมด 2 เครื่อง การ์ดแตกเป็นปุ่ม **Red side** และ **Blue side** ปุ่มที่มีเครื่องอื่นจองอยู่จะกดไม่ได้
- โหมด 1 เครื่อง ได้บทบาท **Lead** (คุมเวลาและกดทั้งสองฝั่ง) โหมด 2 เครื่อง เครื่องฝั่งแดงเป็น Lead เครื่องฝั่งน้ำเงินกดได้เฉพาะเหตุการณ์ของน้ำเงิน

### 4.3 Match (ก่อนเริ่มเกม)

```
┌─────────────────────────────┐
│ Field 1        A2  Game 2/3 │
│ Group A   Series  1 - 0     │
├─────────────────────────────┤
│ RED   ทีมสอง                 │
│ BLUE  สาม                    │
│ [ Swap sides ] ขอแอดมิน      │
├─────────────────────────────┤
│ Field pattern               │
│ [ 1 ] [ 2 ] [ 3 ]  [Random] │
├─────────────────────────────┤
│ [      Start setup 1:00   ] │
│ Skip setup                  │
└─────────────────────────────┘
```

- **Field pattern** เลือกเองหรือกด **Random** ให้ระบบสุ่ม (ข้อ 2.3) Dashboard ขึ้นแบบสนามทันที ล็อกเมื่อเริ่ม Setup
- เกม Replay (FAQ 34) ล็อกแบบเดิมไว้ให้แล้ว เลือกใหม่ไม่ได้
- ถ้าทีมไม่มา มีปุ่ม **Team absent** ส่งคำขอแพ้บายให้แอดมินอนุมัติ (กรรมการไม่ตัดสินแพ้บายเอง)

### 4.4 Setup

- นาฬิกาใหญ่นับ 1:00 ลง
- **Pre-start checklist** (ติ๊กได้ระหว่าง Setup ต้องครบก่อน Start จะกดได้)
  - [ ] Red robot fully inside red box (FAQ 3)
  - [ ] Blue robot fully inside red box
  - [ ] Stands placed as pattern N, both sides (FAQ 4)
- หมด 1:00 ระบบเปลี่ยนเป็น Ready เอง มีเสียงเตือน

### 4.5 Start และนับถอยหลัง

- ปุ่ม **Start** เต็มความกว้าง กดครั้งเดียว ไม่ต้องกดค้าง
- จอขึ้นเลข **3 2 1** ตัวใหญ่ พร้อมเสียงติ๊ด 3 ครั้ง แล้วเสียงยาวตอน **GO** Dashboard นับพร้อมกันจากเวลาเซิร์ฟเวอร์เดียวกัน
- ระหว่างนับถอยหลัง มีปุ่ม **False start** (กดค้าง 1 วินาที) ใช้เมื่อหุ่นออกก่อนสัญญาณ (FAQ 12)

### 4.6 Live (หัวใจของระบบ)

จอแบ่งซ้ายแดง ขวาน้ำเงิน ด้านบนเป็นนาฬิกา ด้านล่างเป็น Checklist ตามลำดับเกณฑ์ ขั้นที่ควรกดต่อไปจะเด่น ขั้นที่ทำแล้วขึ้นเวลากำกับ แต่ทุกขั้นกดได้เสมอเพราะเหตุการณ์จริงอาจข้ามลำดับ

```
┌─────────────────────────────┐
│ 1:12.4            Pattern 2 │
├──────────────┬──────────────┤
│ RED ทีมสอง    │ BLUE สาม      │
├──────────────┼──────────────┤
│ 1 Left red box (5.3)        │
│ [ 0:02.4  1st ]│[  Left box  ]│
├──────────────┼──────────────┤
│ 2 First lift (5.1)          │
│ [ 0:18.0  1st ]│[ 0:21.7     ]│
├──────────────┼──────────────┤
│ 3 Parked stands (5.4)       │
│ [L][C][R]  2  │[L][C][R]  1  │
├──────────────┼──────────────┤
│ 4 Mission complete (6.1)    │
│ auto at 3/3   │ auto at 3/3  │
├──────────────┴──────────────┤
│ Retry R:1  B:0    [ Undo ]  │
│ Leading: RED (6.2 count)    │
└─────────────────────────────┘
```

**ขั้น 1 Left red box** ปุ่มต่อฝั่ง กดตอนหุ่นฝั่งนั้นพ้นกรอบแดงทุกส่วน ระบบบันทึกเวลา ณ วินาทีที่กด ฝั่งที่กดก่อนขึ้นป้าย **1st** กดซ้ำไม่ได้ (ใช้ครั้งแรกเท่านั้น FAQ 28) กดผิดใช้ Undo

**ขั้น 2 First lift** ปุ่มต่อฝั่ง กดเมื่อยกขาทั้ง 4 พ้นพื้นครั้งแรก ป้ายช่วยจำบนปุ่ม "4 legs off the floor" กดได้ครั้งเดียวเหมือนขั้น 1

**ขั้น 3 Parked stands** ช่อง 3 ช่อง L C R ตรงกับช่องสีน้ำเงินบนสนาม แตะเพื่อติดหรือเอาออก
- ติด เมื่อแท่นจอดสำเร็จในช่องนั้น (ขา 4 ขาอยู่ในช่อง แตะพื้น ไม่ได้ถูกดันหรือลาก)
- เอาออก เมื่อแท่นหลุดจากช่อง (FAQ 21) หรือย้ายไปช่องอื่น (FAQ 23)
- ตัวเลขข้างช่องคือจำนวนที่จอดอยู่ตอนนี้
- ป้ายช่วยจำ "Pushed or dragged in does not count" (5.4, FAQ 14)

**ขั้น 4 Mission complete** ไม่ต้องกดเอง เมื่อช่องครบ 3 ระบบบันทึกเวลาครบ หยุดนาฬิกาของฝั่งนั้นทันที (FAQ 33) และล็อกช่องจอดของฝั่งนั้น มีปุ่ม **Not complete** สำหรับกรณีกดผิด (ปลดล็อก นาฬิกาฝั่งนั้นเดินต่อจากเวลาจริง)

**Retry** ปุ่มต่อฝั่ง นับจำนวนครั้งไว้ดูเฉย ๆ ไม่มีผลต่อคะแนน (7.5) แต่ช่วยตอนทบทวนผล

**Undo** ย้อนการกดล่าสุดของเครื่องนี้ ทีละ 1 ครั้ง ย้อนได้ทุกครั้งจนถึงเริ่มเกม

**Leading** บรรทัดเล็กบอกว่าถ้าหมดเวลาตอนนี้ใครชนะ ด้วยข้อไหน ช่วยให้กรรมการเห็นว่าข้อมูลที่ขาดอยู่มีผลหรือไม่

เวลาที่บันทึก มาจากนาฬิกาเครื่องกรรมการที่ปรับให้ตรงกับเซิร์ฟเวอร์แล้ว (ไม่ใช่เวลาที่ข้อมูลไปถึงเซิร์ฟเวอร์) เน็ตช้าจึงไม่ทำให้เวลาเพี้ยน

### 4.7 Review (หลังหมดเวลา หรือครบทั้งสองฝั่ง)

```
┌─────────────────────────────┐
│ Time up 1:30                │
├──────────────┬──────────────┤
│ Final state at 1:30 (5.6)   │
│ Parked  [L][C][R] 2 │ 1     │
│ Complete   -        │ -     │
│ First lift 0:18.0   │0:21.7 │
│ Left box   0:02.4   │0:03.1 │
│ Retries    1        │ 0     │
├──────────────┴──────────────┤
│ Result  RED wins            │
│ Rule 6.2 more stands parked │
├─────────────────────────────┤
│ Checklist before confirm    │
│ [ ] No stand held by robot  │
│ [ ] Teams have seen result  │
├─────────────────────────────┤
│ [   Confirm result   ]      │
└─────────────────────────────┘
```

- ช่องจอดแก้ได้อีกครั้ง เพื่อให้ตรงกับ **สภาพ ณ 1:30** จริง (เช่น หุ่นชนแท่นหลุดตอนวินาทีสุดท้าย FAQ 21 หรือถือค้างอยู่ FAQ 22)
- เวลาแก้ได้ด้วยการแตะแล้วพิมพ์ ระบบบันทึกว่าแก้ใน Review (เห็นในประวัติ)
- **Result** คำนวณสดจากเกณฑ์ข้อ 6 พร้อมเหตุผลเป็นประโยคเดียว เช่น "6.3 ยกแท่นแรกก่อน 0:15.0 กับ 0:20.0"
- ผลเสมอทุกอย่าง ปุ่มเปลี่ยนเป็น **Replay with pattern N** (FAQ 34)
- ไม่มีใครออกกรอบแดง ปุ่มเปลี่ยนเป็น **Referee decides** เลือก Red หรือ Blue (FAQ 35)
- Checklist ก่อนรับรอง 2 ข้อต้องติ๊กครบ ปุ่ม **Confirm result** ถึงจะกดได้ (FAQ 36 ทีมถามได้ก่อนรับรอง)

### 4.8 Next

- คู่ยังไม่จบ ขึ้นผลซีรีส์ และปุ่ม **Next game** กลับไปหน้า Match (เกมใหม่ เลือกแบบสนามใหม่)
- คู่จบ ขึ้น **Match finished ผู้ชนะ** แล้วรอแอดมินเปิดคิวถัดไป

### 4.9 สิ่งที่หน้ากรรมการทำไม่ได้ (ตั้งใจกันพลาด)

- เข้าสนามที่ไม่มีคิว แก้คู่ที่จบแล้ว แก้เกมที่รับรองแล้ว เปลี่ยนฝั่งทีม ตัดสินแพ้บาย ทั้งหมดนี้เป็นงานแอดมิน

## 7. ข้อมูล (เปลี่ยนจาก v2)

### 7.1 ตารางใหม่ `a2_mark` บันทึกเหตุการณ์

| คอลัมน์ | ชนิด | ความหมาย |
|---|---|---|
| `id` | uuid | สร้างที่เครื่องกรรมการ ใช้กันส่งซ้ำ (idempotent) |
| `game_id` | bigint | เกม |
| `side` | text | `red` หรือ `blue` หรือ null (เหตุการณ์ของเกม) |
| `kind` | text | `exit` `lift` `park` `unpark` `retry` `complete_undo` `start` `false_start` |
| `zone` | text | `L` `C` `R` ใช้กับ park unpark |
| `t_ms` | int | เวลาตั้งแต่สัญญาณเริ่ม ตามนาฬิกาเครื่องกรรมการที่ปรับแล้ว |
| `device` | text | เครื่องที่กด |
| `voided` | bool | ถูก Undo หรือแอดมินลบ |
| `source` | text | `live` `review` `admin` |
| `created_at` | timestamptz | เวลาที่เซิร์ฟเวอร์ได้รับ |

กฎตรวจที่เซิร์ฟเวอร์ `t_ms` ต้องอยู่ระหว่าง 0 ถึง `game_ms` และห่างจากเวลาเซิร์ฟเวอร์ไม่เกิน 5 วินาที ถ้าเกิน (เช่น ส่งจากคิวออฟไลน์นาน ๆ) ยังรับ แต่ติดธงให้แอดมินดู

### 7.2 ค่าที่คำนวณจาก `a2_mark` (เก็บในแถว `a2_game` เพื่อให้อ่านเร็ว อัปเดตทุกครั้งที่มีเหตุการณ์)

- `exit_ms` เวลา `exit` ที่น้อยที่สุดที่ไม่ถูก void ของฝั่งนั้น
- `lift_ms` เวลา `lift` ที่น้อยที่สุด
- `zones` สถานะล่าสุดของแต่ละช่อง (เหตุการณ์ park unpark ล่าสุดตาม `t_ms`)
- `parked` จำนวนช่องที่ติด
- `full_ms` เวลาครั้งแรกที่ `parked` แตะ 3 (ไม่นับถ้ามี `complete_undo` หลังจากนั้น)
- `retries` จำนวน retry
- `end_parked` สภาพ ณ ตอนจบ ถ้าครบภารกิจใช้ 3 ถ้าไม่ครบใช้ `parked` ณ `game_ms`

### 7.3 สนาม `a2_field` เพิ่ม

- `ref_mode` `1` หรือ `2`
- `go_at` เวลาเซิร์ฟเวอร์ที่ GO (Countdown จบ) ใช้นับเวลาทุกจอ
- `phase` เพิ่มค่า `ready` `countdown`
- `red_stop_ms` `blue_stop_ms` เวลาที่นาฬิกาย่อยแต่ละฝั่งหยุด (ครบภารกิจ)
- อุปกรณ์ที่จองเก็บใน `a2_fdev` แยก `red_device` `blue_device` `lead_device` (ไม่เปิดให้อ่านสาธารณะเหมือนเดิม)

### 7.4 ตัวตัดสิน `a2_decide` ฉบับ v3

```
input ต่อฝั่ง  full_ms, end_parked, lift_ms, exit_ms   (เวลาปัดเป็นช่วง tie_ms ก่อนเทียบ)
1  ครบฝั่งเดียว                   ฝั่งนั้นชนะ   6.1
2  ครบทั้งคู่ full ไม่เท่ากัน        น้อยกว่าชนะ  6.1
3  ไม่ครบทั้งคู่ end_parked ไม่เท่ากัน มากกว่าชนะ  6.2
4  มีคนยกได้ (lift ไม่ว่างอย่างน้อยฝั่งเดียว)
     ยกได้ฝั่งเดียว                ฝั่งนั้นชนะ   6.3
     ยกได้ทั้งคู่ เวลาไม่เท่ากัน       ก่อนชนะ     6.3
     ยกได้ทั้งคู่ เวลาเท่ากัน         replay     FAQ 34
5  ไม่มีใครยกได้
     ออกกรอบฝั่งเดียว               ฝั่งนั้นชนะ   6.4
     ออกทั้งคู่ เวลาไม่เท่ากัน         ก่อนชนะ     6.4
     ออกทั้งคู่ เวลาเท่ากัน           replay     FAQ 34
     ไม่มีใครออก                   judge      FAQ 35
```

ข้อต่างจาก v2 ในข้อ 4 v2 เทียบเวลาออกกรอบต่อเมื่อเวลายกเท่ากัน ซึ่งเกินกติกา (6.4 ใช้เฉพาะกรณีไม่มีใครยกได้)

### 7.5 RPC ใหม่ของกรรมการ

| RPC | ใช้ทำอะไร |
|---|---|
| `a2_ref_claim(pin, device, field, side)` | จองสนาม side เป็น `lead` `red` `blue` |
| `a2_ref_pattern(..., game, pattern | 'random')` | เลือกหรือสุ่มแบบสนาม |
| `a2_ref_setup(..., action)` | `start` `skip` |
| `a2_ref_check(..., item, on)` | ติ๊ก Pre-start checklist |
| `a2_ref_go(...)` | เริ่ม Countdown ได้ `go_at = now() + 3s` |
| `a2_ref_false_start(...)` | void เหตุการณ์ทั้งหมดของรอบนี้ กลับไป Ready |
| `a2_ref_mark(..., id, side, kind, zone, t_ms)` | บันทึกเหตุการณ์ ส่งซ้ำด้วย id เดิมได้ผลเหมือนเดิม |
| `a2_ref_undo(..., id)` | void เหตุการณ์ |
| `a2_ref_review_set(..., side, field, value)` | แก้ค่าในหน้า Review |
| `a2_ref_confirm(..., game)` | รับรองผล คืน `red` `blue` `replay` `judge` |
| `a2_ref_judge(..., game, side)` | กรรมการตัดสินกรณี FAQ 35 |
| `a2_ref_absent(..., side)` | ขอแพ้บาย ให้แอดมินอนุมัติ |

ทุกตัวตรวจ PIN อุปกรณ์ สนาม session และสิทธิ์ฝั่ง (เครื่องฝั่งน้ำเงินกด `red` ไม่ได้) เหมือน v2

### 7.6 คิวออฟไลน์ของกรรมการ

- ทุกการกดเก็บลง `localStorage` ก่อน แล้วส่ง `a2_ref_mark` ถ้าส่งไม่สำเร็จ ลองใหม่ทุก 2 วินาทีตามลำดับ
- จอกรรมการขึ้นป้าย "Saved on this phone, sending (3)" ให้รู้ว่ายังมีที่ค้าง
- ปุ่ม Confirm result กดไม่ได้จนกว่าคิวจะว่าง

## 10. ลำดับการทำ (เมื่ออนุมัติดีไซน์)

1. ฐานข้อมูล `a2_mark`, คอลัมน์ใหม่ใน `a2_field` `a2_game`, `a2_decide` v3, RPC กรรมการชุดใหม่ พร้อมทดสอบ SQL ทุกกรณีในตารางตัวอย่างข้อ 6 ของกติกา และ FAQ 21, 22, 27, 28, 33, 34, 35

3. Dashboard แทน `/tv/` โหมด Live พร้อม Countdown และนาฬิกาย่อยต่อฝั่ง
4. ปรับแอดมิน ชื่อแท็บอังกฤษ Referee mode Event log ในหน้าแก้เกม
5. ซ้อมจริง 2 สนาม 4 เครื่อง (โหมด 2 เครื่อง) วัดความคลาดเวลาระหว่างเครื่อง ต้องไม่เกิน 0.1 วินาที
